Agent Browser
Pro User Manual

Для кого:
- для администратора или технического пользователя
- для настройки и обслуживания пресетов

Как открыть настройки администратора:
- на главном экране нажмите Settings
- по умолчанию Settings открывается сразу, если администратор не включал блокировку
- если администратор заранее задал переменную среды AGENT_BROWSER_PRO_PASSWORD, при нажатии Settings появится окно ввода пароля
- файл pro-mode.flag рядом с AgentBrowserUI.exe по-прежнему можно использовать как локальный bypass для администратора

Что доступно в Settings:
- выбор активного пресета
- редактирование имени пресета
- выбор SOCKS5 или VLESS
- выбор режима маршрутизации
- ввод и изменение строки подключения
- Test для проверки sing-box config
- Apply для записи core\config.json и активации выбранного пресета
- Duplicate, Rename, Delete для управления пресетами

Работа с пресетом:
1. Откройте AgentBrowserUI.exe.
2. Нажмите Settings.
3. Выберите существующий пресет или создайте новый через Duplicate.
4. При необходимости смените тип подключения:
   - SOCKS5
   - VLESS
5. Выберите режим маршрутизации:
   - `Прокси только для браузера (рекомендуется)` для обычного операторского сценария
   - `Системный TUN (для продвинутых)` только если нужен трафик всей машины через sing-box
6. Вставьте строку подключения.
7. Нажмите Test.
8. Если проверка успешна, нажмите Apply.
9. Закройте Settings.
10. Нажмите Start на главном экране.

Поддерживаемые форматы:
- SOCKS5: host:port или host:port:user:pass
- VLESS: vless://...

Практические правила:
- сначала Test, потом Apply, потом Start
- не меняйте рабочий пресет без причины
- для безопасного изменения используйте Duplicate и тестируйте копию
- если оператору нужен только запуск, не давайте ему доступ к Settings
- `Прокси только для браузера (рекомендуется)` должен быть default режимом для большинства пользователей
- `Системный TUN (для продвинутых)` используйте только если понимаете, что другие приложения на машине тоже могут пойти через этот маршрут
- если на конкретном ПК кнопка Start в UI не доводит пользователя до корректного окна UAC, допускается fallback: оставить UI открытым и запускать Start.exe вручную из папки пакета; для `Системный TUN` используйте `Запуск от имени администратора`

Диагностика:
- ui.log: действия UI
- start.log: запуск браузера и туннеля
- stop.log: остановка процессов
- core\sing-box.log: сетевой runtime лог

Support:
- Export Bundle собирает логи и метаданные в zip
- SupportTool.exe делает то же самое отдельным окном
