Agent Browser
Basic User Manual

Для кого:
- для обычного оператора
- для запуска браузера без изменения технических настроек

Что видно в Basic режиме:
- текущий активный пресет
- текущий режим маршрутизации
- кнопки Test, Start, Stop
- при необходимости Export Bundle и Open Logs
- лампа Connection
- замаскированное описание текущего подключения

Как работать:
1. Запустите AgentBrowserUI.exe.
2. Убедитесь, что на главном экране показан нужный активный пресет.
3. Убедитесь, что режим маршрутизации подходит:
   - `Прокси только для браузера (рекомендуется)` для обычной работы
   - `Системный TUN (для продвинутых)` только если администратор специально так настроил пакет
4. При необходимости нажмите Test.
5. Нажмите Start.
6. Если выбран режим `Системный TUN`, подтвердите запрос Windows UAC, если он появился.
   - если нажать Нет или закрыть окно UAC, сессия не запустится
   - если учётная запись не администратор, может потребоваться пароль администратора этого компьютера
7. Дождитесь, когда откроется браузер.
8. Проверьте лампу Connection:
   - зеленая: соединение работает
   - оранжевая: идет проверка
   - красная: соединение не прошло проверку
9. После работы закройте браузер или нажмите Stop.

Резервный способ запуска:
1. Оставьте AgentBrowserUI.exe открытым.
2. Откройте папку пакета.
3. Если пакет работает в режиме `Системный TUN`, нажмите правой кнопкой на Start.exe и выберите `Запуск от имени администратора`.
4. Если пакет работает в режиме `Прокси только для браузера`, Start.exe можно запускать обычным двойным кликом.
5. После этого браузер должен запуститься, а в AgentBrowserUI.exe появится состояние Running или Connected.

Что можно делать в Basic:
- запускать и останавливать сессию
- запускать тест текущего пресета
- смотреть статус туннеля
- экспортировать support bundle
- открывать папку с логами

Чего не нужно делать в Basic:
- не открывайте Settings, если вам не нужно менять соединение
- не редактируйте файлы в папке вручную

Если что-то не работает:
1. Нажмите Open Logs.
2. Сохраните support bundle через Export Bundle.
3. Передайте архив тому, кто поддерживает пакет.

Если Windows пишет, что операция была отменена пользователем:
- это значит, что не был подтверждён запрос прав администратора для Start.exe
- нажмите Start ещё раз и подтвердите окно UAC
- если через кнопку Start неудобно, запустите Start.exe вручную из папки пакета; для режима `Системный TUN` используйте `Запуск от имени администратора`
- если у вас нет прав администратора, нужен пароль администратора на этом ПК

Если тормозят другие браузеры и программы:
- это означает, что пакет запущен в режиме `Системный TUN`
- в этом режиме трафик всей машины может идти через выбранный сервер
- для обычной работы должен использоваться режим `Прокси только для браузера (рекомендуется)`
