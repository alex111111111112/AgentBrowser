Agent Browser
Basic User Manual

Для кого:
- для обычного оператора
- для запуска браузера без изменения технических настроек

Что видно в Basic режиме:
- текущий активный пресет
- кнопки Test, Start, Stop
- при необходимости Export Bundle и Open Logs
- лампа Connection
- замаскированное описание текущего подключения

Как работать:
1. Запустите AgentBrowserUI.exe.
2. Убедитесь, что на главном экране показан нужный активный пресет.
3. При необходимости нажмите Test.
4. Нажмите Start.
5. Подтвердите запрос Windows UAC, если он появился.
6. Дождитесь, когда откроется браузер.
7. Проверьте лампу Connection:
   - зеленая: соединение работает
   - оранжевая: идет проверка
   - красная: соединение не прошло проверку
8. После работы закройте браузер или нажмите Stop.

Что можно делать в Basic:
- запускать и останавливать сессию
- запускать тест текущего пресета
- смотреть статус туннеля
- экспортировать support bundle
- открывать папку с логами

Чего не нужно делать в Basic:
- не открывайте Settings, если вам не нужно менять соединение
- не редактируйте файлы в папке вручную

Если что-то не работает:
1. Нажмите Open Logs.
2. Сохраните support bundle через Export Bundle.
3. Передайте архив тому, кто поддерживает пакет.
